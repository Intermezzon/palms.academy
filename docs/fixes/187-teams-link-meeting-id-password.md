# Fix: Teams Link Missing Meeting ID and Password (Issue #187)

## Problem

When creating a Teams-link in Palms, the join URL is inserted correctly, but the **Meeting ID** and **Passcode** (password) that may accompany the created meeting are not stored or displayed.

Microsoft Teams meetings include three pieces of connection information:

1. **Join URL** – e.g. `https://teams.microsoft.com/l/meetup-join/19%3ameeting_...`
2. **Meeting ID** – a numeric identifier, e.g. `123 456 789 012`
3. **Passcode** – a short alphanumeric code, e.g. `abc123`

The Meeting ID and Passcode allow participants to join via the Teams app's _"Join with a meeting ID"_ flow, which is important for users on mobile devices or in environments where direct link-clicking is restricted.

## Expected Behaviour

When a user creates or edits a Teams meeting link in Palms, they should be able to supply (and later view) the Meeting ID and Passcode alongside the join URL. These values should be:

- Stored on the meeting/event record.
- Displayed to participants alongside (or below) the join link.
- Included in any calendar invitations or notification emails generated by Palms.

## Data Model Changes

The Teams meeting link component (or the underlying event/activity entity) should be extended with two additional optional fields:

| Field | Type | Description |
|---|---|---|
| `teams_meeting_id` | `string` (max 64) | The numeric Teams Meeting ID, e.g. `123 456 789 012` |
| `teams_passcode` | `string` (max 128) | The alphanumeric passcode / password for the meeting |

Both fields are optional because not all Teams meetings require a passcode and the meeting ID may not always be relevant.

## UI Changes

### Creation / Edit Form

Add two new input fields below the existing Teams join-link URL field:

```
[ Teams join link ] (existing field)
[ Meeting ID      ] (new optional field – numeric, spaces allowed)
[ Passcode        ] (new optional field – text)
```

### Display / Participant View

When the meeting link is rendered for participants, show the additional details beneath the join button/link:

```
[Join Microsoft Teams Meeting]  ← existing join button/link

Meeting ID: 123 456 789 012
Passcode:   abc123
```

If `teams_meeting_id` is empty the "Meeting ID" row should be omitted; likewise for `teams_passcode`.

## Notification / Email Templates

Any email template or calendar invite that currently embeds the Teams join URL should be updated to conditionally append the Meeting ID and Passcode when present:

```
Join Microsoft Teams Meeting
https://teams.microsoft.com/...

Meeting ID: 123 456 789 012
Passcode: abc123
```

## Acceptance Criteria

- [ ] A user can enter a Meeting ID when creating/editing a Teams link.
- [ ] A user can enter a Passcode when creating/editing a Teams link.
- [ ] The Meeting ID and Passcode are persisted to the database.
- [ ] The Meeting ID and Passcode are displayed to participants on the event/activity page.
- [ ] The Meeting ID and Passcode (when present) are included in notification emails and calendar invitations.
- [ ] If either field is left blank it is gracefully omitted from all views and communications.
